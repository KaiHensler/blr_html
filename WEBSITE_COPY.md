## Technical Overview

### Technology Stack

**Frontend:**
- HTML5
- CSS3 (custom properties, CSS Grid, Flexbox)
- Vanilla JavaScript (no frameworks)

**Performance Optimizations:**
- Critical CSS inlined in `<head>` to eliminate render-blocking
- Google Fonts loaded asynchronously with preconnect
- Lazy loading of non-critical resources
- Cached headers via Vercel configuration

**Animations:**
- Scroll reveal effects (IntersectionObserver)
- Parallax scrolling in hero section
- Smooth gradients and glowing effects
- Floating UV orbs with CSS animations
- FAQ accordion with grid-based height animation

### Color System (CSS Variables)
- `--bg-deep: #06060c` (deepest background)
- `--bg-primary: #0a0a14` (main background)
- `--bg-elevated: #111122` (cards, nav)
- `--accent: #7c5cfc` (primary purple)
- `--accent-bright: #a78bfa` (lighter purple)
- `--glow-cyan: #06d6a0` (secondary glow)
- `--text: #e8e6f0` (primary text)

### Fonts
- **Headings:** Outfit (600, 700, 800 weights)
- **Body:** DM Sans (400, 500, 600, 700 weights)
- Loaded from Google Fonts

### Responsiveness
- Desktop-first design
- Tablet breakpoint: 1024px
- Mobile breakpoint: 768px
- Extra small mobile: 480px

### Key JavaScript Features
1. **Navigation:** Scroll spy, hamburger menu toggle
2. **Animations:** Scroll reveal via IntersectionObserver
3. **Parallax:** Hero grid movement on scroll
4. **FAQ:** Accordion toggle with smooth grid animation
5. **Form:** Real-time validation, webhook submission to Make.com
6. **Back to Top:** Smooth scroll with visibility toggle
7. **Page Transitions:** Fade out on internal link clicks

### Form Submission
- Endpoint: Make.com webhook (https://hook.eu2.make.com/...)
- Method: POST
- Content-Type: application/x-www-form-urlencoded
- Fields: name, company, email, phone, message

### Hosted On
- Vercel (deployment platform)
- Cache headers configured in vercel.json
